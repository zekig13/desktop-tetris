# Desktop Tetris

Python ile hazirlanmis, pencere tabanli oynanabilir bir Tetris oyunu.

## Calistirma

Windows'ta `Tetris Oyna.cmd` dosyasina cift tiklayin.

## Kontroller

- Sol / Sag ok: Hareket
- Yukari ok: Dondur
- Asagi ok: Hizli indir
- Bosluk: Sert dusur
- P: Duraklat / devam et
- R: Yeniden baslat

## Teknoloji

- Python 3
- pygame
